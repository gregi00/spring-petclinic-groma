Java 17 application built with Spring Boot, Spring MVC, Thymeleaf, and Spring Data JPA. It serves HTML pages and veterinarian data endpoints, persists clinic records through JPA repositories, and uses H2 by default with MySQL and PostgreSQL profiles available.
